# Rubik's Cube Solver 🧩

This is a simple Rubik's Cube simulator and solver written in JavaScript.  
It scrambles a virtual cube, displays its state, and then solves it step-by-step (not optimal, but functional).

## 🔧 Features

- Object-Oriented cube representation
- Manual face rotations
- Scramble and reverse-solve logic
- Console-based cube visualization

## 🚀 How to Run

1. Download or clone the repo
2. Open `index.html` in your browser
3. Open browser **Console** to view the steps

## 💡 Technologies Used

- HTML
- JavaScript (ES6+)
